## Key source-derived distinctions

### Cellular data vs Wi-Fi
- Cellular data uses the mobile carrier's network.
- Wi-Fi joins an existing local wireless network.
- Wi-Fi settings can be disabled to force fallback to cellular data when needed.

### SIM activation vs provisioning
- Activation enables the device to connect to the carrier using SIM information.
- Provisioning configures which carrier services are available for that device.

### Physical SIM vs eSIM
- Physical SIM is removable and can often be moved between compatible devices.
- eSIM is embedded and uses downloadable carrier profiles.

### Hotspot
- The phone uses its cellular data connection to create a personal Wi-Fi network.
- Connected devices consume the phone's data plan.
- Extended hotspot use can increase battery drain.

### Bluetooth pairing
Source workflow:
1. Enable Bluetooth.
2. Put the second device into pairing mode.
3. Search for devices.
4. Select the device.
5. Enter a PIN if required.

The transcript says `pen code`; the reviewed Uyghur uses the intended **PIN code** while preserving the original English source unchanged.

### Location
The source covers:
- GPS satellites
- cellular signal-based triangulation
- per-app location permissions
- high-accuracy mode combining GPS, Wi-Fi, Bluetooth and cellular networks

### EMM / MDM ownership models
- COPE: company owns device, limited personal use allowed.
- CYOD: employee chooses from an approved list; company retains ownership/control.
- BYOD: employee owns device; management is more limited and focused on corporate data.

### Synchronization
The source covers:
- account/cloud-based synchronization
- data caps
- Wi-Fi-only synchronization
- calendars and contacts
- email status synchronization
- cloud-storage file access and editing

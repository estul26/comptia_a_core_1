## Internet connection types

### ISP
The source defines an Internet Service Provider as an organization/company that provides Internet access to individuals, businesses and other entities.

Source considerations:
- throughput
- pricing
- location / availability

### Wired connections

**Fiber optic**
- fiber-optic cable
- glass/plastic optical fibers
- light pulses
- one of the fastest/reliable source-described options
- relatively more expensive
- commonly deployed in urban areas, per source

**Cable**
- coaxial copper used for cable TV infrastructure
- high-speed access
- sufficient for most homes/small businesses
- lower source-described maximum than fiber
- usually cheaper / wider coverage than fiber
- shared customer bandwidth

**DSL**
- Digital Subscriber Line
- existing copper telephone lines / POTS
- DSL modem required
- slower than fiber/cable, per source
- cost-efficient / widespread because existing telephone infrastructure is reused

### Wireless connections

**Satellite**
- communication satellites + antenna
- useful when wired infrastructure is unavailable/impractical
- source describes it as expensive/slow in remote-use context
- ~35,000 km geostationary distance stated by source
- latency caused by signal travel distance
- weather can interfere with radio signals

**Cellular**
- mobile Internet
- smartphones/tablets/laptops
- antennas
- interconnected base stations/cell towers
- geographic coverage while mobile

**WISP**
- Wireless Internet Service Provider
- fixed wireless
- local dish/antenna to provider tower
- rural/underserved areas
- simple setup / less extensive infrastructure
- source says weather can affect it and speeds may be lower than wired

No DOCSIS, DSL subtype, PON, mobile generation or fixed-wireless frequency detail was added.

## Network types

### PAN
- smallest source-covered network
- individual use
- a few meters
- source example: smartphone + Bluetooth headset + smartwatch

### LAN
- small geographic area
- home, small office, building
- resource sharing
- source initially calls it wired/Ethernet but later says LAN can also be wireless

The reviewed translation does not hide this source inconsistency.

### WLAN
- Wireless Local Area Network
- local connectivity using wireless signals such as Wi-Fi
- can connect into/extend access to a wired LAN

### WAN
- larger than LAN/WLAN
- connects multiple LANs or remote locations
- city/country/continent-scale examples
- source says Internet can be considered a massive WAN

### MAN
- larger than LAN, smaller than WAN
- city/metropolitan area
- connects multiple LANs in a geographic area

### SAN
- Storage Area Network
- dedicated high-speed storage network
- shared pools of storage devices presented to multiple servers
- source examples: server rooms / data centers
- large data volumes / efficient storage management and access

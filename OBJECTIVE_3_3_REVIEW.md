Original English transcript remains unchanged.

## RAM types

### RAM basics
- Random Access Memory
- working data/programs currently in use
- volatile; contents lost when power is removed
- source analogy: RAM as the center of a busy information intersection

### DIMM
- desktop form factor
- circuit board holding memory chips
- retaining clips
- keyed/notched
- do not force incompatible/misaligned modules

### SODIMM
- smaller form factor
- laptops / compact systems
- inserted at an angle and pressed down, per source
- keyed for compatibility/orientation

### DDR
Source progression:
- DDR3
- DDR4
- DDR5

Source says each newer generation improves speed/efficiency and generations are not interchangeable due to slot/electrical/performance differences.

### ECC
Source:
- additional circuitry for error detection/correction
- server/critical-system focus
- financial transactions and medical records examples
- higher cost trade-off

### Example module specification
Source example:
- 8 GB
- DDR4
- 2666
- PC4-21300
- theoretical bandwidth: 21,300 MB/s

The transcript describes 2666 as MHz / cycles per second. This is preserved as source teaching and not externally reconciled.

## RAM channels

### Single channel
- one pathway
- single-lane-road analogy
- can bottleneck under high data demand

### Dual channel
- two pathways
- two-lane-highway analogy
- source says doubled capacity/transfer model
- matching modules / designated slots
- source later clearly says at least one module in each channel

Internal contradiction:
the source earlier says `install a single RAM module or identical RAM modules in pairs`. The reviewed text explicitly notes this conflict and uses the later internally consistent two-channel population explanation.

### Triple channel
- three pathways
- source associates slots in multiples of three

### Quad channel
- four pathways
- source associates slots in multiples of four
- color coding may or may not be present

### Motherboard documentation
The source repeatedly emphasizes checking motherboard documentation for compatible RAM and correct slot population.

## Translation approach

- Preserve source organization and exam emphasis.
- Correct only clear transcription artifacts.
- Explicitly document internal source conflicts.
- Preserve source-stated speed/bandwidth terminology without importing outside corrections.
- Do not add RAM characteristics absent from the transcript.

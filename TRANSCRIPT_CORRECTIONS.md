# Transcript corrections used in the study display

The original English transcript is preserved unchanged under `source/`.

The website's embedded English study text corrects a few obvious speech-to-text errors so they do not become study mistakes:

- `DBR`, `DBR3`, `DBR4`, `DBR5` → `DDR`, `DDR3`, `DDR4`, `DDR5`
- `TBR4` → `DDR4`
- `DIM` / `SO-DIM` in the RAM form-factor lesson → `DIMM` / `SODIMM`
- `complimentary domains` → `complementary domains`
- `5A+ Core 1 exam domains` → `5 A+ Core 1 exam domains`

The DDR/DIMM/SODIMM terminology matches the CompTIA A+ 220-1201 RAM objective terminology.

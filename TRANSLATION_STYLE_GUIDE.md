# Uyghur Translation Style Guide — CompTIA A+ Core 1

This guide defines the translation rules for the deep-review pass.

## 1. Translation goal

The Uyghur should:
- preserve the technical meaning of the English source;
- sound like natural written Uyghur, not word-for-word machine translation;
- remain useful for CompTIA exam study;
- keep globally recognized abbreviations and product/protocol names recognizable.

## 2. Technical-term rule

Keep canonical abbreviations unchanged:
`RAM`, `SODIMM`, `HDD`, `SSD`, `NIC`, `WLAN`, `WWAN`, `NFC`, `Wi-Fi`, `Bluetooth`, `RJ45`.

At the first important occurrence, use:
**natural Uyghur explanation + English term/abbreviation in parentheses**.

Example:
- `ئانا تاختا (motherboard)`
- `كۇنۇپكا قاپقىقى (keycap)`
- `ئېكران توپلىمى (display assembly)`

After the first explanation, prefer the Uyghur wording or the abbreviation instead of repeatedly inserting raw English words.

## 3. Avoid awkward literal translations

### monitor
In the exam objective, `monitor hardware` does not simply mean “look at it”.
Preferred:
- `قاتتىق دېتال ھالىتىنى نازارەت قىلىش`
- `ھالىتىنى تەكشۈرۈش`

Avoid:
- `قاتتىق دېتالنى كۆزىتىش` when it sounds like physically watching the device.

### replacement techniques
Preferred:
- `زاپچاس ئالماشتۇرۇش ئۇسۇللىرى`
- `مۇۋاپىق ئالماشتۇرۇش ئۇسۇلىنى قوللىنىش`

Avoid:
- `ئالماشتۇرۇش تېخنىكىسى` as a literal calque.

### Random Access Memory
Keep `RAM (Random Access Memory)` as the canonical term and explain its function naturally:
- `سىستېما ئىشلىۋاتقاندا لازىملىق سانلىق مەلۇماتنى ۋاقىتلىق ساقلايدىغان تېز ئىچكى ساقلىغۇچ`

Do not force an unnatural literal Uyghur expansion if it hurts comprehension.

## 4. Code-switching rule

Avoid sentences such as:
`application level دىن setting نى verify قىلىڭ`

Prefer:
`ئالدى بىلەن ئەپ سەۋىيەسىدە تەكشۈرۈپ، تەڭشەكلەرنىڭ توغرىلىقىنى جەزملەشتۈرۈڭ.`

English should remain only where it helps identify an exam term.

## 6. Source corrections

The English transcript is speech-to-text and may contain transcription mistakes.
When a correction is necessary for technical accuracy:
1. do not silently pretend the transcript was correct;
2. document it in the translation audit;
3. preserve the original English source file unchanged.

Example in Objective 1.1:
the transcript says `wireless wide area network, or WLAN cards`; the intended abbreviation is **WWAN**.
The reviewed Uyghur uses `WWAN` and records the correction.

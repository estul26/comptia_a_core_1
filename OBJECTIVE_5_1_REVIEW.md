## Symptom groups

### No power
Possible source causes:
- faulty PSU
- loose power connections to motherboard/CPU/components
- PSU not receiving wall power

### POST / beep codes
Source teaching:
- successful POST → one beep
- failure → beep sequence
Possible areas:
- motherboard/chipset/capacitors/corrosion/loose components
- failed/unseated RAM
- CPU failure/disconnected CPU fan

The one-beep rule is treated as source model, not universal firmware behavior.

### Black screen
Possible causes:
- motherboard
- graphics card
- display
- PSU

### Crash screens
Source examples:
- Windows BSOD
- macOS spinning pinwheel
Possible causes:
- incompatible/outdated drivers
- damaged motherboard
- failing RAM
- malfunctioning graphics card
- overheating CPU

### Overheating
Possible causes:
- poor airflow/ventilation/cooling
- dust/debris
- failing fan
Effects:
- instability
- unexpected shutdowns
- damage

### Burning smell
Possible sources:
- PSU
- motherboard
- overheating CPU
- potentially other hardware
Required source action:
- power off
- unplug
- seek professional assistance

### Sluggish performance
Possible causes:
- insufficient CPU

- insufficient available storage

### Random shutdown
Possible causes:
- faulty PSU
- insufficient PSU wattage
- overheating CPU/GPU

### Frequent app crashes
Possible causes:
- faulty RAM
- software/version/driver conflict
- corrupted system files
- insufficient storage

### Unusual noise

### Swollen capacitors
Source causes:
- excessive heat
- prolonged use
- manufacturing defects
Effects:
- instability
- erratic behavior
- complete failure
- possible electrolyte leakage/smoke/burning smell

### Incorrect date/time
The transcript conflates CMOS with CMOS battery.
Reviewed lesson keeps the supported troubleshooting point:
- CMOS battery backs up date/time/BIOS-setting retention
- depleted/degraded battery can cause incorrect date/time
Potential effects:
- file timestamps
- software licensing
- scheduled tasks
